# Contributing

Contributions are welcome.

To contribute:

1. Fork the repository
2. Create a new branch
3. Make your changes
4. Submit a Pull Request

Issues can be opened for bug reports, feature requests, or improvements.

---

## Testing Policy

As new functionality is added to the project, contributors should also add tests that verify the behavior of the new feature whenever possible.

Automated tests should be included with pull requests when new functionality significantly changes the behavior of the software.

This helps ensure the reliability and stability of the project as it grows.
